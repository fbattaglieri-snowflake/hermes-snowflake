# Hermes Container Image

The image is based on Ubuntu 24.04 and installs Hermes Agent via the official upstream installer during the build. The source code of Hermes Agent is not redistributed here.

## What the Image Adds

- **Cortex proxy** (`/opt/cortex_proxy.py`): resolves six deviations between Snowflake Cortex and the OpenAI Chat Completions protocol. Runs on `127.0.0.1:8080` inside the container with a watchdog.
- **`hermes_configure.py`**: patches the `config.yaml` generated by the Hermes installer to configure Snowflake Cortex as the LLM provider.
- **`spcs_token.sh`**: reads the rotating SPCS service OAuth token from `/snowflake/session/token` and emits it as JSON with a short `expires_in`, preventing stale-token errors during long sessions.
- **`/opt/hermes-seed`**: a copy of the Hermes configuration and skills saved before runtime. Used to restore missing files on the block volume without overwriting user changes.

## Block Volume Behaviour

The SPCS service specification mounts a block volume at `/root` (size declared in the spec). This mount hides everything the image writes under `/root` at build time. `start.sh` restores missing files from `/opt/hermes-seed` using `cp -a -n` (no-clobber) at every boot.

## Build

```bash
docker build --platform linux/amd64 \
  -t hermes-snowflake:latest \
  docker/hermes
```

## Key Environment Variables

| Variable | Default | Purpose |
|---|---|---|
| `SNOWFLAKE_HOST` | injected by SPCS | Cortex API endpoint; also used by `hermes_configure.py`. |
| `OLLAMA_INTERNAL_URL` | `http://ollama-service:11434` | Ollama endpoint for the GPU provider. Override with your SPCS DNS name. |
| `HERMES_PROVIDER` | `snowflake-cortex-proxy` | Active provider at startup. |
| `HERMES_MODEL` | `claude-sonnet-5` | Default model. |
| `HERMES_SELFTEST` | `1` | Set to `0` to skip the boot self-test. |
| `CF_TUNNEL_TOKEN` | — | Cloudflare tunnel token. Tunnel not started if absent. |
| `SSH_PUBLIC_KEY` | — | Injected from Snowflake Secret. SSH access enabled if set. |
| `TS_AUTHKEY` | — | Tailscale auth key. Client connectivity not available if absent. |
| `HERMES_DASHBOARD_BASIC_AUTH_USERNAME` | — | Dashboard username. Set in `.env` from Snowflake Secret. |
| `HERMES_DASHBOARD_BASIC_AUTH_PASSWORD_HASH` | — | Scrypt hash. Set in `.env` from Snowflake Secret. |
| `HERMES_DASHBOARD_BASIC_AUTH_SECRET` | — | Stable cookie signing secret. Must not change between restarts. |
